API 配置指南

3 分钟搞定。地址只需填域名，系统自动补全路径。直连优先，被拦截自动走云端代理。

一、连接原理（先看这个）

浏览器→①直连→AI API / 中转站
②被拦截？→云端代理 /api/chat→AI API / 中转站

直连优先DeepSeek / OpenAI 等官方 API 支持跨域，直连最快、无中转。

代理兜底多数中转站不支持跨域，浏览器直连会被拦。此时自动切到 Cloudflare 云端代理转发，对用户无感。

💡 所以：填中转站地址也能用，只是会自动走代理。两条路都帮你接通了。

二、通用配置 3 步

1打开 设置 → 模型 API (LLM)
2「当前语言模型」选一个；填 API Key 和 地址（填域名即可，如 https://api.deepseek.com）
3点 测试连接，显示 ✓ 即成功 → 滑到底部 保存并应用

地址栏会自动补全：/v1/chat/completions（OpenAI类）、/v1/messages（Claude）、:generateContent（Gemini）。填完整地址也行。

四、中转站配置（哈基米等）

通用中转站（OpenAI 兼容，最常见）

1「当前模型」选 自定义 / 中转站
2协议格式选 OpenAI 兼容（绝大多数中转站都是这个）
3地址填中转站域名，如 https://api.xxx.com（不用手动加路径）
4填中转站给你的 Key 和要用的 Model ID（如 gpt-4o / deepseek-chat）
5测试连接 → 保存

哈基米（Hajimi，Gemini 中转）

1「当前模型」选 自定义 / 中转站
2协议格式选 Gemini 兼容
3地址填哈基米域名，如 https://你的哈基米地址.com
4填 Key（哈基米通常是 Gemini Key 或自定义令牌）+ Model ID gemini-2.5-pro

💡 哈基米若同时提供 OpenAI 兼容接口，也可选「OpenAI 兼容」+ 填 /v1/chat/completions 路径的域名，两种都试试哪个通。

五、常见报错对照

提示原因 & 解决
401 / unauthorizedAPI Key 错误或已失效 → 重新复制粘贴 Key
404 / not found地址或 Model ID 不对 → 检查地址域名、模型名拼写
请求超时中转站无响应 → 换中转站，或检查是否需要科学上网
无法访问目标地址代理也连不上 → 地址填错了 / 中转站挂了 / 需科学上网
直连被拦截且代理未就绪Cloudflare Functions 未部署 → 确认 functions/api/ 目录已一起上传
未填写 API Key没填 Key → 设置里填好 Key 再保存

六、直连 vs 代理 小结

  • 官方 API（DeepSeek/OpenAI）→ 直连即可，最快。
  • 中转站（哈基米等）→ 直连通常被 CORS 拦，自动走云端代理，照样能用。
  • 两条路自动切换，你只管填对 Key 和地址。
  • 云端代理依赖 functions/api/ 部署到 Cloudflare Pages，别漏传。
